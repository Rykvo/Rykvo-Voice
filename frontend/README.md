# Rykvo Voice

原生静态前端，登录通过同源 Go 服务验证。Apple 风格，无运行时框架、CDN 或外部字体。

## 打开

局域网访问：`http://本机IP/`；域名访问：`https://域名/gly`。域名根路径不显示后台。登录页与业务页由 Go 按会话分别下发；业务静态资源也校验登录。普通静态文件服务器不具备访问隔离，不用于部署。登录服务源码位于交付工作区的 `outputs/rykvo-backend/`。

## 当前状态

- 管理入口未登录返回 `login.html`，已登录返回 `index.html`，两者不互相加载。登录卡片在会话检查完成前保持隐藏，恢复会话不闪现登录表单。登录页验证服务端会话，无会话显示账号、密码与登录按钮。支持密码显隐、回车提交、重复提交保护和退出登录；没有前端万能密码或跳过入口。密码哈希和会话保存在 PostgreSQL。

- 模块、电话、信息默认为空，不生成演示记录。使用独立的 `rykvo-voice-` 存储命名空间，不读取旧预览数据。旧浏览器存储不作为程序交付内容，也不会被清空。
- 页面布局、表单校验、搜索、日期、线路选择、删除确认及本地设置可用。电话与短信仍是本地预览行为，SIP 账号保存在页面内存中；不等同于已连接设备、发送短信或注册 SIP。
- 所有功能的接口入口见 `api.js`，协议、字段与逐页接入位置见 `BACKEND.md`。登录已绑定 `/api/session`，管理员修改已绑定 `/api/administrator`，修改后撤销所有登录会话；云服务器已接入 Cloudflare Tunnel 同源接口，详情见 `TUNNEL.md`；其他业务需完成数据绑定及真实服务联调。
- 不清空 localStorage。资料、设置与密钥不是缓存；不以清理为由删除用户数据。

## 界面约定

地址栏不显示页面片段，切换页面保持域名的 `/gly` 或局域网 IP 根路径与必要端口；当前页面保存在本标签页 sessionStorage，刷新后恢复。旧 `#devices`、`#modules` 等书签仍可打开，对应页面载入后去掉片段。

- 侧栏无数量角标及外侧焦点框；品牌图标悬停使用普通箭头，无提示。退出位于侧栏通用下方，独立于显示开关。
- 连续点击品牌图标 10 次后验证独立密码，验证成功才打开“功能显示”。计数在服务端完成，间隔超过 2 秒或点击别处重置。
- 功能显示采用左右分组，窄屏自动单列。只有右侧开关可切换，文字不可拖选；该窗口及密码验证窗口点击背景不关闭，其他窗口保持点击背景关闭。
- 左侧下方可修改独立密码，仅需当前密码、新密码；保存密码与完成按钮同排。密码哈希保存在 PostgreSQL，与登录密码独立；修改后所有功能显示授权失效。
- 独立密码授权有效期 5 分钟，关闭窗口立即撤销；服务端限制同一账号 15 分钟内最多 5 次失败尝试。前端不保存密码或授权标志。
- 显示开关只隐藏界面，不删除数据或停止后台任务，不是权限控制。隐藏全部项目后仍能通过品牌图标恢复。
- 通话和信息列表使用细滚动条，悬停或键盘聚焦时显示，不引起宽度跳动。
- 电话与新短信共用线路选择器：随机、模块标签、号码；已有会话保留原线路。
- SIP 列表：IP:端口、用户名、密码、模块、操作；用户名搜索；固定模块支持多选。
- SIP 通话记录只显示当前账号按所选本地日期筛选的呼出，逐条显示、不合并。接通绿色，未接通红色。
- “通话统计”按每通已接通电话向上取整为分钟，最低 1 分钟，再汇总为小时和分；不统计来电或未接通，超过 24 小时不归零。
- 自动清理只显示“0 为关闭”。按保留天数清理过期通话及短信，保留账号和设置；服务端记录需服务端调度清理。

## 文件职责

| 文件                                                     | 职责                                 |
| -------------------------------------------------------- | ------------------------------------ |
| `index.html`、`app.js`                                   | 页面入口、导航                       |
| `shared.js`、`styles.css`                                | 公共工具、基础样式                   |
| `login.html`、`login.js`、`auth.css`                     | 独立登录页                           |
| `auth.js`                                                | 主界面会话与退出                     |
| `http.js`、`base.css`、`fields.css`、`password-input.js` | 两页共用请求与基础控件               |
| `api.js`                                                 | 同源请求、取消、超时、错误、实时订阅 |
| `visibility.js`、`cleanup.js`                            | 显示设置、保留天数                   |
| `module-data.js`、`lines.js`、`line-picker.*`            | 模块数据、共享线路与选择器           |
| `modules.*`、`cellular.*`                                | 模块与蜂窝网络                       |
| `phone.*`、`messages.*`、`countries.js`                  | 电话、信息、本地区号格式化           |
| `sip.*`、`sip-history.js`、`calendar.*`                  | SIP 账号与通话记录、日期选择         |
| `forms.*`、`lists.css`、`context-menu.js`                | 共用表单、列表、右键与确认           |
| `admin.js`、`developer.js`、`server.js`                  | 管理员、开发者、云服务器             |
| `assets/`                                                | 已引用的本地图标                     |

源码维护目录另有 `tests/`，使用 `node --test tests/*.test.cjs` 执行回归检查。测试、历史预览、开发工具、缓存和压缩包不放入桌面交付目录。
