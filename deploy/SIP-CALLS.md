# SIP 电话适配

## 已确认规则（2026-09-26）

这是用户确认的产品规则。后续修改先核对本文，不从界面占位行为推断电话能力。

| 项目 | 规则 |
| --- | --- |
| 账号登录 | 一个账号只保留一个有效客户端注册。B 登录成功后撤销 A；A 的旧续注册、旧呼叫和迟到回调均失效。 |
| 顶号、改密、删除 | 立即停止相关声音、结束该账号通话和振铃、撤销旧注册。改密须新密码重新认证；删除后拒绝注册。 |
| 模块分配 | 账号与模块多对多，一个模块可以分给多个账号。 |
| 全部 | 从当前空闲且真正具备通话能力的全部模块中随机选择。 |
| 固定 | 只在勾选范围内选择空闲可用模块，绝不越界。 |
| 并发限制 | 每账号、每模块各一通电话；拨号、响铃、接通和未完成清理都占用资源。 |
| 来电 | 只通知分配了该模块、注册有效、开启接听且空闲的 SIP 用户；忙碌用户跳过。 |
| 多人空闲 | 同时响铃；首个有效接听者独占通话，其余停止响铃。迟到的 SIP 200 OK 仍须 ACK 后 BYE。 |
| 无人可接 | 所有人忙碌、离线、关闭接听，或都拒接/响铃超时，结束新来电，不影响其他通话。 |
| 模块已占用 | 拒绝该模块第二通来电，不启用呼叫等待，不打断原电话。 |
| 网页 | 只拨出、不接来电，与 SIP 共用模块占用管理。 |
| 账号状态 | 在线、通话中、离线。通话中包括拨号、响铃及清理中的资源占用；以真实注册及呼叫事件为准。 |
| 局域网 | 未配置或已注销 SIP 服务器时使用局域网地址，允许 1024–65535 中的可用端口，不套用云端范围。云端连接中/故障/状态未知不擅自切换线路；已有账号端口不自动改写。 |
| 端口 | 局域网端口框显示“输入端口”；云端模式在输入框内以占位文字显示服务器分配范围，不固定 5060、不预填端口；编辑保留原值。配置刷新不覆盖输入，读取失败不猜范围，前后端拒绝越界和保留端口。 |
| 界面 | 复用当前页面，状态列位于模块和操作之间，不显示模拟在线或模拟接通。 |

关闭接听只停止该账号的待接分支，不打断已经接通的电话。若其他用户仍在响铃，不能连带挂断他们的来电。

## 通话承载与网络隔离

- 同一套 SIP 账号/调度规则分别接蜂窝语音和 VoWiFi/IMS 两种适配器。两条线路各自验收，不能把短信成功、网络在线或 IMS 注册成功作为通话验收。
- SIP 电话服务器是远程 SIP 客户端的接入通道，不是全局代理；承载 SIP 注册、续期/保活、呼叫信令和通话媒体，VPN 自身也有握手/保活。
- 空闲时保持注册与 VPN 所需的小流量以便接听，不实现为只有拨打时才连接。
- 短信、彩信、eSIM、网页管理、更新、主机服务器和其他主机流量继续走原路径，不绑定 SIP VPN 地址。不修改主机默认路由和 DNS。
- VoWiFi 到运营商 ePDG/IMS 的网络与 SIP 客户端到主机的 VPN 是两段不同链路；不能因名称都有 SIP/IMS 就合并路由。
- 现有 `deploy/sip-network.py` 仅对 VPN 源地址配置专用路由表。接入电话服务时延续该方式，并验证业务流量与默认路由未被接管。

## 调度核心接入约定

`backend/internal/telephony` 是内部调度核心，不监听 SIP、不认证网络请求，不发送实际电话。尚未接入生产主进程；不因通过调度测试就开启电话能力。

- `Register` 只能由完成真实 SIP 认证的适配器调用，携带数据库凭据版本。`Refresh` 只续期原注册 ID；注册 ID 不是网络鉴权令牌。旧注册自动续期不得变成新的登录顶回 B。
- SIP 的 REGISTER 同时用于初次注册和续期，需在适配器中绑定真实客户端实例、连接和鉴权 nonce，处理重传及 CSeq；不能每次 REGISTER 都调用 `Register`。普通 SIP 无通用的“让 APP 返回登录页”命令，只能保证服务器端撤权。
- 账号修改/删除与注册认证须使用同一账号级事务/版本栅栏；不得让数据库写入失败变成假成功。重启后注册和占用不能从缓存恢复为在线，先与模块核对并清理孤立呼叫。
- 所有操作返回待执行 `Action`。驱动串行处理状态事件和命令，执行前用 `ActionCurrent` 丢弃已被顶号/挂机取代的拨号、响铃和接听。即使返回错误，也必须处理返回的清理动作。
- `StopMedia` 先停止本地转发，再发送终止信令。撤权即刻生效；模块及客户端的清理确认前不释放模块占用。清理失败保持隔离，绝不用定时器假设已挂断。
- `ClientClosed` / `ModuleClosed` 仅由真实结束事件或核实后的清理结果驱动。`Connected` 仅由通话及媒体均已就绪的驱动调用。ACK、重传等协议细节由适配器负责。
- `Tick` 使用单个服务级定时器处理注册过期、拨号/响铃超时，不为每行列表开计时器。前端轮询只读状态，不负责释放占用。
- 模块必须明确报告语音可用才加入选择池；“在线”或“IMS 注册成功”不等于支持当前编码的双向通话。

## 已发现的接入风险

- Wi-Fi 私有 IPC 已桥接 IMS 呼叫控制；SIP 调度尚未调用这些接口，PCM 音频通路未接。接口存在不等于手机可以通话。
- RTP 协商已收紧为实际具备的单声道 8 kHz G.711；不宣告未实现的 AMR/AMR-WB 或电话事件。仅接受 AMR 的运营商仍需真实编码器和实机验收。
- 云端 VPN 已有网络配置接口，真正 SIP 信令与 RTP 均需使用其返回的端口范围，分开预留监听端口和媒体端口，避免冲突。
- 不清空用户会话、短信、彩信、SIM 配置或回滚备份；本阶段不发送实际电话，不改变模块射频或现有网络。

## 注册阶段验收

- SIP 服务按账号端口监听 UDP/TCP；局域网仅绑定本机私网 IPv4，云端仅绑定专用 SIP VPN 地址。不开通 TLS/全局代理，不修改防火墙、默认路由或 DNS。
- 注册有效期最多 300 秒，过期离线；同一账号新客户端替换旧客户端。旧客户端的同一 Call-ID/实例续注册被拒绝一小时；改密、改用户名/端口、删除即时撤销当前注册。服务重启后全部重新鉴权，不从缓存恢复在线。
- 普通 SIP 的新 REGISTER 与重新登录没有统一 UI 语义；被替换 APP 主动创建全新实例并持有有效密码时视作新的认证登录。此限制不能用“手机自动退出登录页”表述掩盖。
- 通话承载尚未接入，已认证 INVITE 明确返回 503，不伪造 200/接通；当前版本只可验收账号管理和手机注册。
- 自动测试覆盖 UDP/TCP 实际套接字、双摘要算法、错误密码、源地址/端口隔离、防重放、过期、顶号、改密、删除、端口冲突及配置切换。

## v1.6.2 兼容检查

实机抓到 Zoiper v2.10 和 PortSIP iOS v12 的未鉴权 REGISTER 重试。针对这两类旧客户端仅下发已支持的 MD5 挑战，其余客户端继续优先 SHA-256；不因 User-Agent 跳过密码、来源、端口或防重放验证。真实手机完成 200 OK 注册前不报告登录成功。

## v1.6.3 通话驱动基础

- 仅新增私有控制接口，不新增公开拨号 API，不开放真实 SIP INVITE；callsReady 仍为 false。
- IMS 挂机先停止 PCM，保留 ending 到有效 INVITE 终结/BYE 确认；CANCEL 200、超时及丢失 IPC 回复均不释放模块。
- 迟到 200 必须 ACK/BYE；重传 200 重发 ACK。来电重传复用会话，晚到 CANCEL 不结束已接听的会话；同模块第二通来电拒绝。
- 后续先完成音频 IPC、EC20 驱动和 SIP 对话桥，再接现有调度、账号撤权及真实记录；接听 ACK/超时、媒体中断和手机双向声音仍需专项验收。
- 按 RFC 3261 第 9、13、15 节实现取消/结束语义；本项目对清理结果采用更保守的隔离策略。

- CLCC 的 LTE 数据上下文不计作语音占用；CHUP 结束语音，清理后恢复 PCM/GPS 输出设置。超时的旧 AT 响应不得确认新挂机；未确认清理保持占用。
- SIP 账号状态接真实调度；呼叫元数据写入 sip_call_records，不存录音。记录页面接入及来电分支仍待完成。
- 用户只批准一通 01 → 02，接通后不超过 20 秒；未进行之前不得写成已验收。自动测试中的替身驱动只用于协议与资源管理回归，不代表实机声音通过。
