# SIP 电话

## 产品规则

| 项目 | 规则 |
| --- | --- |
| 账号登录 | 允许同一账号多台手机同时注册；不挤号、不因已有手机在线返回 480。每台独立续期、注销和过期。 |
| 登录占用 | 删除在线独占与换机冷却；只有呼叫占用限制。登录另一台手机不影响当前通话。 |
| 改密、删除 | 立即停止相关声音、结束该账号通话和振铃、撤销旧注册。改密须新密码重新认证；删除后拒绝注册。其他手机登录失败不影响当前通话。 |
| 模块分配 | 账号与模块多对多，一个模块可以分给多个账号。 |
| 全部 | 从当前空闲且真正具备通话能力的全部模块中随机选择。 |
| 固定 | 只在勾选范围内选择空闲可用模块，绝不越界。 |
| 随机选择 | 每次呼出独立随机；至少两个可用模块时排除该账号上一次使用的模块，仅一个可用时继续使用。各账号独立，不按被叫号码固定，不要求用完一轮。 |
| 并发限制 | 每账号、每模块各一通电话；拨号、响铃、接通和未完成清理都占用资源。 |
| 来电 | 只通知分配了该模块、注册有效、开启接听且空闲的 SIP 用户；忙碌用户跳过。 |
| 多人空闲 | 同时响铃；首个有效接听者独占通话，其余停止响铃。迟到的 SIP 200 OK 仍须 ACK 后 BYE。 |
| 无人可接 | 所有人忙碌、离线、关闭接听，或都拒接/响铃超时，结束新来电，不影响其他通话。 |
| 模块已占用 | 拒绝该模块第二通来电，不启用呼叫等待，不打断原电话。 |
| 网页 | 仅管理模块、信息和 SIP 账号，不提供浏览器拨打或接听；SIP 电话位于侧栏“信息”下方。 |
| 账号状态 | 在线、通话中、结束中、离线。清理期间显示结束中并保留占用；以真实注册及呼叫事件为准。 |
| 局域网 | 未配置或已注销 SIP 服务器时使用局域网地址，允许 1024–65535 中的可用端口，不套用云端范围。云端连接中/故障/状态未知不擅自切换线路；已有账号端口不自动改写。 |
| 端口 | 局域网端口框显示“输入端口”；云端模式在输入框内以占位文字显示服务器分配范围，不固定 5060、不预填端口；编辑保留原值。配置刷新不覆盖输入，读取失败不猜范围，前后端拒绝越界和保留端口。 |
| 界面 | 复用当前页面，状态列位于模块和操作之间，不显示模拟在线或模拟接通。 |

关闭接听只停止该账号的待接分支，不打断已经接通的电话。若其他用户仍在响铃，不能连带挂断他们的来电。

## 多端登录

- 同账号多台 APP 可同时在线；每个注册端点独立认证、续期、注销和过期，保持摘要验证及防重放。
- 同账号呼入与呼出合计最多一通，含拨号、响铃、接通及未完成清理；第二通返回 486，不发起另一模块呼叫。登录不占通话名额。
- 来电同时通知同账号所有有效空闲端点；第一台接听独占，其余停止响铃。不同账号共享模块的首接规则不变。
- 同一来电按账号只保存一条记录，只统计实际接听设备的时长；同账号另一台拒接不覆盖已接听结果。
- 改密或删除撤销该账号全部端点并立即结束通话；一台退出不注销其他手机，也不打断其他手机正在接听的分支。
- 注册续期、过期或移除不挂断已接通通话；失效注册不能发起新呼叫。新注册不接管旧通话，通话中的账号仍保持占用。改密、删除、停用及模块权限收回仍立即结束相关通话。
- APP 退到后台不代表注销；第三方 iOS APP 的系统推送尚未接入，不保证被挂起时仍响铃。
- 模块已确认挂机、媒体停止、SIP 分支完成或终止等待到期后释放通话占用，与 APP 是否在线、续期或注销无关。硬件未确认挂机时继续隔离，不用界面状态或超时冒充模块空闲。

## 通话记录

- 列表操作列并列显示“通话记录”“详情”；记录直接按该行账号打开，详情不保留重复入口。
- 沿用账号、日期、对方号码、模块、状态、时长和统计页面；以服务端真实记录为准，不读取旧本地占位记录。
- 呼出状态：拨号中、响铃中、通话中、已接通、无人接听、对方拒接、对方占线、已取消、拨打失败。
- 呼入状态：来电响铃、通话中、已接听、未接来电、已拒接、本机忙碌、对方取消、其他用户已接听、接听失败。明确的卡、模块、网络、音频错误保留具体原因；历史未保存取消方向的记录仍为已取消，不补猜。
- 共享模块的第二个拨号若无其他授权空闲模块，显示模块忙碌，不打断、不排队。账号忙碌与对方占线分开。
- 全部关闭接听时挂断新来电，不生成通话记录。只有开启接听且实际收到呼叫的账号才记录该来电；其余拨出记录照常保留。
- 多人响铃中一人接听，其余账号显示其他用户已接听，不标为拒接；一人拒接不打断其他分支。
- 底部按当前账号、所选日期分别显示呼出时长、呼入时长；统计包含全部分页，仅累加已接听且有真实结束时间的本账号记录。其他用户已接听和未接通不计时。
- 时长只由真实接听和结束事件产生；清理等待不计入通话。继续既有每通向上取整分钟展示，不代表运营商计费。未知结束时间留空，不用重启时间冒充。

## 通话承载与网络隔离

- 同一套 SIP 账号/调度规则分别接蜂窝语音和 VoWiFi/IMS 两种适配器。两条线路各自验收，不能把短信成功、网络在线或 IMS 注册成功作为通话验收。
- SIP 电话服务器是远程 SIP 客户端的接入通道，不是全局代理；承载 SIP 注册、续期/保活、呼叫信令和通话媒体，VPN 自身也有握手/保活。
- 空闲时保持注册与 VPN 所需的小流量以便接听，不实现为只有拨打时才连接。
- SIP 专用 VPN 不接管短信、彩信、eSIM、网页管理、更新或其他主机流量。主网络与每网络 VLESS 独立管理这些出口，规则见 [网络配置](NETWORK-CONFIG.md)。
- VoWiFi 到运营商 ePDG/IMS 的网络与 SIP 客户端到主机的 VPN 是两段不同链路；不能因名称都有 SIP/IMS 就合并路由。
- 现有 `deploy/sip-network.py` 仅对 VPN 源地址配置专用路由表。接入电话服务时延续该方式，并验证业务流量与默认路由未被接管。


## 调度核心接入约定

`backend/internal/telephony` 是内部调度核心，不监听 SIP、不认证网络请求，不发送实际电话。蜂窝和 Wi-Fi SIP 拨出及来电已接入此核心；协议回归不替代实际运营商和手机验收。

- `Register` 只能由完成真实 SIP 认证的适配器调用，携带数据库凭据版本。`Refresh` 只续期原注册 ID；注册 ID 不是网络鉴权令牌。每台设备独立续期，不撤销其他端点。
- SIP 的 REGISTER 同时用于初次注册和续期，需在适配器中绑定真实客户端实例、连接和鉴权 nonce，处理重传及 CSeq；不能每次 REGISTER 都调用 `Register`。普通 SIP 无通用的“让 APP 返回登录页”命令，只能保证服务器端撤权。
- 账号修改/删除与注册认证须使用同一账号级事务/版本栅栏；不得让数据库写入失败变成假成功。重启后注册和占用不能从缓存恢复为在线，先与模块核对并清理孤立呼叫。
- 所有操作返回待执行 `Action`。驱动串行处理状态事件和命令，执行前用 `ActionCurrent` 丢弃已被撤权/重建/挂机取代的拨号、响铃和接听。即使返回错误，也必须处理返回的清理动作。
- `StopMedia` 先停止本地转发，再发送终止信令。撤权即刻生效；模块必须真实确认挂机，媒体任务必须停止。客户端终止信令走有界事务清理，丢失回复不无限占用账号，也不撤销仍有效的注册。
- `ClientClosed` 由客户端结束事件或已终止的本地 SIP 清理驱动；`ModuleClosed` 仅由真实模块结束事件或核实后的清理结果驱动。`Connected` 仅由通话及媒体均已就绪的驱动调用。ACK、重传等协议细节由适配器负责。
- `Tick` 使用单个服务级定时器处理注册过期、拨号/响铃超时，不为每行列表开计时器。前端轮询只读状态，不负责释放占用。
- 模块必须明确报告语音可用才加入选择池；“在线”或“IMS 注册成功”不等于支持当前编码的双向通话。

## 媒体与验证

- Wi-Fi 通过私有控制与独立 PCM 流接入 SIP 调度，下行彩铃在运营商确认早期媒体、编码协商和内部音频就绪后开放；上行麦克风仍等待真实接听及 APP ACK。实际运营商收发声音仍须验收。
- RTP 只协商实际可用的编码：G.711、运营商 AMR/AMR-WB、APP Opus；未接入 EVS 或独立 telephone-event，不宣告这些能力。实际运营商通话须单独验收。
- 云端 VPN 已有网络配置接口，真正 SIP 信令与 RTP 均需使用其返回的端口范围，分开预留监听端口和媒体端口，避免冲突。
- 不清空用户会话、短信、彩信、SIM 配置或回滚备份；本次由用户 APP 自行拨打验收，不自动呼叫或改变现有模块射频配置。


## 结束原因

以真实接听、拒接、取消和正常挂机信令记录结果。媒体停止后的清理错误不覆盖已经确认的对方挂机；真正的编解码与音频故障保留具体原因。新账号默认关闭接听，现有账号设置保持不变。

## 音频

APP 侧支持实际可用的 G.711 / Opus，运营商侧支持 G.711 / AMR / AMR-WB。每通独立编解码和资源释放，内部私有 PCM 不读取外接模拟麦克风。库不可用时不宣告相应编码。运营商能力与手机双向听感单独验收。

## 清理与诊断

- 挂断清理超过 60 秒仍未确认，重建该模块的 IMS 连接；完成旧连接清理后才释放占用，不用超时冒充结束。
- SIP 呼出异常按设置次数通知 Telegram；0 为关闭。占线、拒接、无人接听、主动取消、来电和已接通后的卡顿不计入呼出失败告警。
- 音频日志中的 RTP 为 APP 到主机，CarrierRTP 为运营商到主机，PCMDropped 为本地队列丢弃样本。Missing 包含静音抑制，不直接等于网络丢包率。

- Wi-Fi 通话状态变化通过独立通知唤醒 SIP；内部状态检查 100 毫秒，心跳仍为 500 毫秒，不增加页面轮询。
