# 网络配置

在「通用 → 网络配置」管理主网络、模块分配及每条网络的 VLESS。列表仅显示已配置、已有模块分配或已保存 VPN 的网络，连接状态显示在名称下方。

## 主网络

- 同时只开启一个；开启 B 会关闭 A 的主网络开关，不关闭 A 网卡。
- 原来使用 A 的模块保留在 A，并显示为已分配；切换主网络不搬移模块。
- 所选网口拔掉或消失持续 5 秒后，检测其他已识别线路（包含模块网络），选择能联网的线路供主机共用。原网口重新连接后回到原选择。
- 网口仍连接但 Internet、DHCP 或 VPN 临时失败，不自动换线；备用网口仍连接时也不因临时断网反复切换。没有可用线路则保留选择。
- 自动切换不移动模块绑定；未显式分配的模块仍使用原手动主网络。候选探测绑定出口，已开启 VPN 的线路不绕过 VPN。
- 不改网卡地址、系统主路由表或网络管理器配置，使用项目自己的策略路由。已连接的局域网 IP 仍可访问后台，不强制跳转网址。
- 切换出口需要可用的 `systemd-resolved` 管理 DNS；缺失时停止切换并提示，不自行替换系统解析配置。

## 模块分配

- 每个模块只分配一条网络，一条网络可分配多个模块。主网络也提供「分配」。
- 开启 B 自动解除 A，无需先关闭；关闭 B 后使用主网络，未设置主网络时使用系统默认网络，不恢复旧分配。
- 分配一次保存；保存失败保留原分配。切换后 Wi-Fi 通话需要重新连接，旧连接清理确认前不启动新连接。
- 通话、短信、彩信及维护任务占用期间禁止改线，后端同步检查。提交结果不明时先回读，不重复写入。
- 断线保留绑定，不擅自换出口或开启蜂窝数据；重连期间保存最终选择，旧连接清理确认后再启动。
- 按稳定设备身份识别网卡，保留改名、分配和重启后的配置；设备身份冲突不猜测。

## VLESS

在网络「详情」粘贴节点链接，保存后在该行开启 VPN。当前支持 VLESS TCP/raw，TLS 或无 TLS；不支持的参数明确提示。无 TLS 的节点链路不加密。

- VPN 对该网络的出口生效，使用该网络的模块也走 VPN；主网络启用 VPN 时，主机默认外发流量同样走 VPN。
- 保留局域网管理回程及明确的专用服务路由。VPN 故障阻止直连，不静默泄漏到原出口；服务自动尝试恢复。
- 先关闭 VPN 再修改或移除节点。节点明文仅向已登录管理员显示，主机配置保存在 root 私有目录。
- 「检测连接」显示通过该节点检测到的出口 IP，不代表运营商注册或业务已成功。
- IPv4/IPv6、DNS、模块独立路由统一处理；节点服务端需支持所需 UDP 流量，Wi-Fi 通话仍取决于运营商与节点可达性。

## 业务路径

| 业务 | 路径 |
| --- | --- |
| Wi-Fi 通话、短信 | 分配网络上的该 SIM 的 IMS/ePDG 会话；开启 VPN 后通过该网络的 VPN |
| Wi-Fi 彩信 | 同一出口上的该 SIM 独立 MMS 承载，DNS 与连接一起绑定 |
| 蜂窝通话、短信 | SIM 自身的蜂窝通道，不因网页 VPN 开关改成互联网发送 |
| 蜂窝彩信 | SIM 的 MMS APN/数据通道 |
| SIP 客户端接入 | 原 SIP 专用 VPN/局域网，与模块到运营商的链路分开 |

## 自动接入与维护

- 开机先恢复隔离规则和路由，再启动网页与后台连接；不等所有网口就绪，不关闭系统的全局网络等待。

- 每 15 秒检查新增物理以太网或手机 USB 共享。已有静态配置、手动禁用、Wi-Fi 登录、桥接和蜂窝 APN 不自动改写。
- 新 DHCP 使用独立路由表，不抢占系统默认网络或发布 DNS；同网段、同网关的多出口保持隔离。
- 网络服务使用独立权限与资源限制，网页进程不获得网络管理权限。页面离开停止轮询，刷新不覆盖正在编辑的内容。
- 升级备份网络配置并保留已有业务；失败恢复程序，不覆盖业务数据库。卸载仅清理项目拥有的规则、路由、DNS 修改及配置。
- 详细网络组件日志：`/var/lib/rykvo-update/network-components.log`。主网络与 VLESS 配置位于 `/var/lib/rykvo-network`，不放入网页或发布包。

自动回归见 [测试](TESTING.md)。真实运营商通话、短信和彩信分别验收，节点检测通过不替代实卡验证。
