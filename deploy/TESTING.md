# 测试

在仓库根目录执行：
```bash
node --test frontend/tests/*.test.cjs
python3 -m unittest discover -s tests
bash -n install.sh && bash -n deploy.sh
cd backend && go test ./... && go vet ./...
```

- Python 系统服务与网络隔离测试在 Linux 执行。
- 数据库测试使用全新、名称以 `_test` 结尾的隔离数据库，设置 `TEST_DATABASE_URL`；不连接生产数据库。
- CI 额外运行数据库、竞态、协议模糊测试、独立网络命名空间、arm64 音频及双架构构建。
- 界面检查桌面、窄屏、深浅色、错误提示和重复提交；不得用模拟状态冒充实际业务结果。
- 发布前核对 RVU 签名、加密认证与包内清单、版本、编译提交、资源和 SHA-256，检查危险路径、错误包和降级拒绝。
- 打包压缩：标准 gzip 解压后完整 tar 逐字节一致；损坏、截断、追加内容、压缩失败及超时均停止构建并保留原包。双架构仍由 1.1.0 原始升级器校验，不裁剪运行文件。
- 通话双向声音、短信彩信、eSIM 与运营商续期分别实测；自动测试不替代实卡验收。
- eSIM：空卡保留原始失败，未启用配置可完成下载，身份变化仍拦截；协议诊断不含激活码，不重放写卡。
- 验证产物、截图和临时记录保存在仓库外，结束后清理测试资源。

## 每次发布的跨版本检查

| 场景 | 必须核对 |
| --- | --- |
| 全新安装 | 一条命令自动验签并配置统一密钥；管理员初始化正常；无旧文件依赖 |
| 新发布线 1.1.0 → 目标版 | 原始升级器能验证完整新 RVU，两个架构均通过；旧数据直接迁移 |
| 每个已发布的支持版本 → 目标版 | 跳过所有中间包，使用各版结构与脱敏数据夹具核对迁移，不只测上一版 |
| 目标版 → 目标版 | 修复安装可重复执行，不重置账号、配置、密钥和业务数据 |
| 新版 → 旧版 | 拒绝降级；错误密钥、伪造签名、越界路径与超限包均拒绝 |
| 中断与失败 | 上传续传、迁移重试、健康检查失败恢复；保留业务与恢复记录 |

- 构建先验证 `tests/fixtures/updater-1.1.0/SHA256.json`，再用对应初版升级器验收真实新产物；不得以当前实现替换固定基线。旧发布线主机重新安装，不放宽降级保护。
- `test_install_key.py` 在临时目录测试首次配置和复用密钥；root 集成仍只使用临时路径，不触碰生产密钥。
- 合成的 1.1.8 等测试包仅证明版本比较、协议与调度，不代表真实未来版本或数据库迁移已验收。迁移改动须补充隔离数据库夹具、失败恢复测试及数据前后对照。
- 每次发布记录起始版本、目标版本、架构、包摘要、迁移及恢复结果。任一受支持旧版失败即停止发布，不以“全量包”代替验收。

## 模块固定网络
- 普通单元测试检查稳定身份、DNS 过滤、配置版本冲突、忙时准入、重启重载和重复迁移。
- CI 的独立网络命名空间创建两个相同网段/网关/本机 IP 的出口，分别验证 UDP、TCP、DNS；断线不能走另一路，退出后清理专用规则，主路由保持不变。测试拒绝在 PID 1 的网络命名空间运行。
- 人工验收：真实网线/手机 USB 的拔插和主机重启、IMS 注册与双向声音、短信和彩信各自收发、SIP APP 与 Webhook 原路径、忙时改线拒绝。未完成实卡测试时不得宣称运营商业务已全部通过。

## 自动外部网络
- `python3 -m unittest discover -s tests -p test_network_auto.py`：未托管网卡、管理员配置保护、隔离路由、两类管理器、幂等与清理。
- `sudo unshare --mount --net python3 tests/network_auto_netns.py`：独立挂载和网络命名空间运行原生 networkd/DHCP，两条同地址/网关网络不改变主机路由和 DNS；拒绝在原主机命名空间执行。
- 实机核对新增 USB 的租约、重插与重启发现；已有主机/API/SIP VPN 路径不变。DHCP 通过不等于运营商通话/短信/彩信通过。

## 页面与域名恢复
- 分配窗口：模块号码、当前网络、跨网络直接切换、关闭后回主网络、忙时保护、离线拒绝、即时保存与失败回读、特殊字符、多模块、手机窄屏及深色主题。列表无刷新按钮、无模块汇总列；关闭页面停止轮询。
- 默认路由：分别验证 IPv4/IPv6、metric、等价多路径、断链与 VPN 默认路由，不把备用或离线网络标成主机默认。
- 域名恢复：已保存连接的临时 API/DNS 失败与限流退避重试、取消及时退出；授权/凭据错误、删除中和未启用连接不循环重试。实机重启恢复另行验收。

- SIP 接听后立即会话刷新：ACK 之前完成首接选择，UDP/TCP 与并发接听、迟到 200 OK 清理回归。

## API 容量与上游压测
- `TestDeveloperBudget*`：持续补充、突发上限、分类隔离、并发扣额、来源表容量与清理。
- `TestDeveloperWorkCapacity`：16 请求、4 图片处理上限及释放；内联彩信与附件引用不能绕过图片准入；内联 image 同时扣上传额度，attachmentId 不重复扣上传额度。
- `TestDeveloperBusyBeforeDatabase`：过载在鉴权数据库查询前快速返回 503 + Retry-After。
- `TestDeveloper120ModuleRequestLoad`：120 模块 × 10 次/分钟平滑提交，加每秒一次增量查询（模拟时间，不发短信）。
- `TestDeveloperStatusReadCapacityDoesNotRaiseSending`：25 次/秒提交与 50 次/秒查询共存；查询仍有突发边界，发送、图片及工作并发上限保持不变。
- `TestMessageCapacityAndFairness`：64 路上限、120 模块轮流调度；持久化夹具验证慢模块不拖住其他 119 个模块、无重复发送。
- API `/api/v1`、`/gly/api/v1` 的 Nginx 连接限制与管理页面分开，关闭请求体预缓冲；检查 `nginx -t`。
- 上游实机从 4～8 请求并发逐步增加，按 Retry-After 加随机延迟退避；先文字后彩信，记录受理延迟、错误码、队列积压、过期和未知结果。真实发送由维护者确认，自动化不接生产号码。
- 模拟测试不代表 120 个真实模块的运营商吞吐；主机 CPU、内存、USB、电源和带宽均需观察。

## 模块短信清理
- `TestCellularCleanup*`、`TestCellularStatusReportStore`：先提交后逐条删除、分段与彩信通知原文、重复归档重试、多存储区、索引复用、换卡、取消、失败保留及原 CPMS 恢复。
- 实机核对支持的模块 `CMGR/CMGD` 行为、入库前后存储数量、断电重连与换卡；主机历史消息保留。清理不支持时保留记录，不用整库删除代替。

## 分配交互与快速重连
- 浏览器：点击模块行、号码、内部空白不改变分配；空白遮罩关闭窗口。各网络均提供分配，只有开关改变选择；主网络与 VPN 分栏，手机卡片复用原控件。
- `TestModuleNetworkRebind*`：旧连接清理期间反复保存选择，只启动最终目标，无硬件重叠；未确认清理继续隔离。
- 数据库：重连中关闭再开启持久化成功，重启加载最终选择；实际业务忙、修订冲突和其他网络占用仍受保护。

## 主网络与 VLESS
- `test_network_control.py`：管理员鉴权、同源与 CSRF、节点解析、版本冲突、忙时保护、默认模块固定化及节点检测。
- `test_network_runtime.py`：无全局自动路由、DNS 保护、配置原子写入、失败恢复、缺少 DNS 服务时拒绝切换及保留未修改的 DNS。
- `network_runtime_netns.py`：隔离命名空间验证主网络切换、断线回退、清理恢复；`network_core_netns.py` 使用实际核心验证 IPv4/IPv6 流量及反复启停不覆盖模块策略规则。
- 新安装、1.1.0 升级、同版恢复及卸载检查网络服务、核心、配置快照和自有路由清理。包内不得包含节点凭据。
- 实机分别验证各出口、DNS、局域网管理回程、运营商注册与业务；自动回归不替代这些结果。

## 收件与 Wi-Fi 恢复
- 收件回归覆盖不支持的状态报告存储区、单段拼接头、损坏记录隔离、提交失败保留、先入库后删除及槽位复用保护。
- Wi-Fi 传输或工作进程临时故障按 15 秒、30 秒、1 分钟、2 分钟、5 分钟退避；恢复后重置。认证拒绝、SIM 状态不符、业务占用和未确认清理不盲目重连。
- SIP 随机选择回归覆盖账号隔离、不连续重复、仅一个可用模块及候选范围限制；不发起真实呼叫。

## Webhook 积压
- `TestWebhookDatabase` 使用独立 `TEST_WEBHOOK_DATABASE_URL`：旧状态合并、事件补拉、重复迁移、单批 512 上限、Retry-After 持久化及收信隔离。
- 24 个状态请求持续阻塞时，8 条收信仍可完成；回调目标使用内存替身，不向公网发送。
- 150 虚拟模块主机联测另行核对回调最久等待、入库延迟、未知结果与恢复；通过单元测试不等于实机容量达标。

## 批量对接
- Runtime 数据库回归覆盖批量部分受理、重复 ID、正文冲突、当前卡版本、删除记录脱敏和逐项限流。
- DeveloperBulkLeavesPriorityHeadroom 验证逐条扣预算与单条入口余量；最多 4 个批量请求，不提高物理模块并发。
- Text 合同回归覆盖多主机隔离、未知结果批量查询、老版本回退、MMS 附件复用及优先单条回复。

## 结果超时
- Runtime 数据库回归覆盖未发送任务到期、发送结果未知 30 分钟、迟到成功与每轮 200 条有界收尾。
- 已接收、已送达、入站消息及未到期任务保持原状态；超时不启动发送、不重新排队。
- Text 按首次提交后的第 1、10、30 分钟查询，最多 3 次有效查询；重复回调、退款和迟到成功补扣均验证幂等。

## Wi-Fi 清理分类与重启准入
- 隔离网络命名空间模拟 IPv4/IPv6 路由与规则被外部删除；清理后重新读取内核，确认私有资源为空，新连接能使用原槽位，主路由不变。
- 实际删除失败、残留路由/规则、读取失败或无效清单继续阻断；重复 Close 保留失败结果，不用 90 秒等待代替清理证据。
- 清理阻塞直接显示 Wi-Fi 通话异常，不依赖通知阈值；有真实重连任务时才显示连接或恢复状态。
- IKE 运行时 reset/断线仍交付数据面；Close 只报告本地资源关闭失败，不重复历史网络错误。
- 远端 IKE Delete 发送失败仅在本地关闭成功且诊断回调存在时降为警告；本地关闭失败继续阻断。
- IMS / 隧道 / 射频 / 未知清理错误经过私有 IPC 保持类别，不泄露上游原文。
- 远端注销或释放警告不覆盖用于退避重连的原始诊断。
- 已知清理未确认时，按钮准入与执行一致，API 不创建注定失败的重启任务；普通运行中的 Wi-Fi 仍允许有序取消后重启。
- 列表优先显示当前 Wi-Fi 故障，不用历史重启任务替代实时状态。
- 实机另验：断网→恢复、健康模块重启、Wi-Fi 运行中重启、未确认清理仍拒绝、运营商拒绝不盲目重试。已有主机未经确认不升级。

## 专用路由与告警恢复
- 独立网络命名空间删除 IPv4/IPv6 标记规则、出口默认路由、保护路由和直连路由；旧会话取消，新租约重建，主机主路由保持不变。
- 内核路由检查不启动外部进程；状态读取失败有上限，不把单次读取中断当作确定掉线。
- Wi-Fi 连续未注册 5 分钟后按原次数阈值累计；连接成功重置，轮询之间短暂成功也保留证据。
- 已注册或已关闭时不显示旧 Wi-Fi 告警；其他硬件、短信和 SIP 故障保留。
- 隔离数据库验证发送前复核、启动恢复期间延后、注册成功取消旧通知且不消耗发送重试次数。
- 实机验收另查应用重启、主机重启后的注册与告警；隔离路由测试不代表运营商永不断线。
- 实际失败次数触发一次完整恢复；确认旧连接清理、射频等待、新连接验证后才放行告警，恢复后取消通知。忙碌、关闭、换卡、限流、清理未确认不强行执行。
- 收件 Webhook 验证单条完整正文、空短信、乱序分片、单段 UDH、重复 TPDU 与二进制 WAP 通知，不提前发布空正文收件事件。

## SIP 清理和音频方向

- 清理重试不延长 60 秒期限；到期只触发一次会话恢复，不把仍待确认的通话改成已结束。
- 正常挂断及已关闭会话不触发恢复；清理中保持占用，页面显示结束中。
- 运营商接收统计与本地 PCM 丢弃样本分开，最大状态帧不超限，旧的无统计适配器仍可工作。
- 实机由用户拨打同模块对照，分别检查两个方向的音频；未完成听感验证不宣称卡顿已修复。

## G.711 抗抖动

- 正常音频逐样本不变；缺包、扩容补偿、5 毫秒衔接、60 毫秒淡出、静音和满幅输入均有回归。
- 250 毫秒突发延迟、乱序、序号与时间戳回绕后保持 20 毫秒节奏；不隐瞒缺包或重放过期包。
- 仅在网络稳定且前后均为收到的静音时缩减缓冲；讲话、缺包和持续迟到时保持原缓冲。
- 重置清除音频历史；原 Opus/AMR 解码补偿不变。合成波形误差与性能测试不替代实卡听感。

## SIP 注册与通话
- 注册续期、注销后重注册、注册过期：已接通通话继续，未接通呼叫仍按原保护退出。
- 注册移除后改密、删除、停用、撤销模块权限：旧通话仍立即结束。
- 新注册不接管旧对话或绕过占用；旧对话的有效 BYE 可结束通话，伪造标签拒绝。
- 记录真正结束动作原因及 BYE 成功、拒绝、超时、传输错误；不记录密码或令牌。
- 实机分别验证 Yak 前后台切换、注册刷新、双方挂机和 IMS 断线；本地协议测试不代替实机结果。

## 通话、启动及备用出口
- 183 彩铃有真实 RTP，最终 200 使用同一 SDP；接听前不发麦克风，取消和双方挂机保持身份与占用保护。
- 音频时钟跳变需连续包确认；单个坏包、重复、乱序及旧音频不复位。仅协商变化重置音源，普通续期保留 NAT 与缓冲。
- 原网口仍连接但无 Internet／DHCP 不换线；拔线防抖、备用探测失败、模块共用、VPN 不旁路、原线插回和多候选轮转。
- 命名空间验证主路由不变、模块默认绑定不移动、项目规则完整清理；启动必须先安装防泄漏规则再通知应用就绪。
- 原版和精简 Tunnel 在 amd64／arm64 验证启动；新 RVU 继续经过 1.1.0 独立升级器校验。
- 硬件扫描保留热插拔与代际检查，不缓存设备身份；64 模块分组与只读扫描基准分别验证。
- 实机另测双向通话、彩铃、双方挂机、断线插拔和开机时间；未安装的代码不计作实机通过。
