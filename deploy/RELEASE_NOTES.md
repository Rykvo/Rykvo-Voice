# v1.6.11

- 接入 Wi-Fi SIP 拨出与双向音频，复用当前账号、模块分配和独占通话规则。
- 为每通话建立认证的私有 PCM 通道，音频与短信、彩信存储传输分开；无新增公网监听。
- Wi-Fi 呼叫使用既有 IMS 隧道，不争抢串口、不改默认路由或 DNS，不在故障时自动切到蜂窝。
- 接听和编码协商完成后才开放音频；挂断、撤权及媒体断开停止转发，运营商结束未确认时保留占用。
- 保留已获用户确认的蜂窝音质修复、RTP 缓冲和外接模拟麦克风常关，不增加降噪或音量增强。
- 增加私有音频帧边界、双向样本、身份隔离、断线清理、占用及真实 SIP/RTP 套接字回归测试。
- 清理过时的拨出能力标记和开发进度说明，页面保持不变。

Wi-Fi 拨出目前协商 PCMA/PCMU（G.711）；实际运营商接通和双向声音需用户 APP 验收。仅接受 AMR/AMR-WB 的运营商、SIP 来电及网页拨号不在本版完成范围。
