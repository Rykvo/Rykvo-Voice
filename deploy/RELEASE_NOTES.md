# v1.6.10

- RTP 接收改用 60 ms 抗抖动缓冲，按时间戳输出，过滤重复、过迟和其他音频流的数据，不再按到达顺序直接拼接。
- 保持 20 ms 音频节拍，丢帧或静音抑制留下的时间空档补静音；缓存固定上限，长时间停顿后不突发重放旧声音。
- USB 首段音频攒齐一块后再播放，保留原样本；不添加降噪、自动增益、变声或音量增强，模拟麦克风继续常关。
- 通话结束仅记录包乱序、重复、迟到、缺少样本及 USB 流控数量，不记录声音、手机号或凭据。缺少样本不直接等于网络丢包。
- 增加真实 UDP 乱序/重复、时间戳和序号回绕、不同包长、断流、取消、缓冲边界及模糊测试。
- 保持现有页面、账号、短信彩信、默认路由和 DNS 不变。

这次优化针对已确认的接收顺序和缓冲缺口；用户反馈的句尾咔哒声、轻微断续仍需实际 APP 通话复测，不将自动测试当作实机音质验收。Wi-Fi 音频、来电及网页拨号仍未完成。
