# v1.5.23

- 彩信按 SIM 归属及 MVNO 身份自动匹配配置库；漫游只切换匹配的协议，不把驻留运营商当作 SIM 运营商。
- 去掉下载网关的运营商域名特例和固定端口限制，支持通知中的独立域名/IP 及配置库中的 MMSC、代理端口，包括 3HK 的 10021。
- 下载及 DNS 绑定收件 SIM 的蜂窝 PDP 或 Wi-Fi 彩信承载；拒绝本机、链路本地和多播地址，不回退主机网络，不改变数据漫游开关。
- 自动恢复近期在地址校验阶段失败的入站下载；不重发已受理或结果未知的彩信。
- Wi-Fi 彩信请求投递报告，按同 SIM、MMSC 消息 ID 和收件人唯一关联；只有 Retrieved 才确认送达。
- 保留真实发送状态，网络受理不冒充实际送达；未实测运营商和 3HK Wi-Fi 注册仍单独标记未验收。
