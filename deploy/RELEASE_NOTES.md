# v1.5.4

- 按 3GPP TS 31.103 增加通用 ISIM 身份读取：IMPI、IMPU、IMS 域名直接来自当前卡，不按模块编号或电话号码猜测。
- IMS 注册优先使用完整且校验通过的卡内身份；确认无 ISIM 时保留原有 USIM 派生流程。显式身份配置仍保留优先级。
- IMS 使用 ISIM 鉴权时不再污染后续 ePDG/EAP 的默认 USIM 应用选择。
- 支持逻辑通道和基础通道读取、分块、多条身份、APDU 长度协商、通道清理及换卡检查；异常或不完整身份不发送至网络。
- 兼容 IMPU 列表中的空备用记录（80 00 + FF），保留非空的有效身份；必填字段或整组身份为空仍拒绝。已在实卡上通过卡内身份完成 IMS 注册。
- 增加运营商差异文档、回归/竞态/模糊测试；保留现有 Wi-Fi 开关、射频策略和号码修复。

这是通用兼容层的增量，不是“全部运营商已适配”。3HK 05 的候选版本实测仍在初始 IMS REGISTER 收到 403；该卡未发现 ISIM，读取改动没有解决此拒绝。通用 TS.43 开通、实际接入地信息、全部运营商实卡通话和 MMS 验收仍未完成。

v1.5.3 因误判空备用记录而未通过主机验收，已回滚并从 Latest 撤下；请使用本版本。
