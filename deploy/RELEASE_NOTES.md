# v1.6.12

- 补齐 Wi-Fi 通话媒体路由：从运营商 SDP 获取音频端点，只在该 SIM 的 IMS 专用源地址路由表增加精确主机路由。
- 校验协商的地址族、UDP 端口及 CHILD_SA 流量选择器；复用地址引用计数，通话结束释放，隧道关闭兜底清理。
- 保留注册信令路由、主机默认路由和 DNS，不接管其他业务网络。
- 接听确认省略 SDP 时，仅复用同一对话已确认的可靠临时应答；无有效音频、不同对话或非法新 SDP 仍结束通话。
- 补充固定枚举的音频失败阶段，正确记录接听响应码；不记录声音、原始 SIP、号码或凭据。
- 增加 IPv4/IPv6 隔离路由、选择器边界、引用释放及接听状态回归。页面和已验收的蜂窝音频处理保持不变。

运营商实际接通、双向声音及重复呼叫仍需实机验收。仅支持 G.711；AMR/AMR-WB、SIP 来电及网页拨号未在本版完成。
