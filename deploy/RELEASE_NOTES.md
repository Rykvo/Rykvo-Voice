# v1.5.30

- SIP 电话服务器接入云端 HTTPS 配置接口，独立 WireGuard 通道，不改变主机服务器、默认路由及 DNS。
- 连接、注销、更换 SIP 服务器与开机恢复；仅实际 VPN 握手成功才显示已连接。
- 接入码不落浏览器存储，私钥仅保存在主机受限目录；不执行云端配置中的脚本。
- 预留电话引擎绑定地址、公网地址及端口范围，本版不开放 SIP 账号、拨号或音频功能。
- 接入地址示例显示 https://sip.example.com/api/connect，省略 HTTPS 时自动补齐并回显。
- 注销时关闭本机 VPN 并清除服务器配置及密钥，保留稳定安装标识；云端客户端仍由云端管理。
